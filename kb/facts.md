TicketPilot
Customer Support Portal
Overview
TicketPilot is a customer support platform that helps businesses manage customer tickets, track service level agreements (SLAs), and improve customer satisfaction. The platform provides a centralized dashboard for support teams to view, prioritize, and respond to customer inquiries efficiently.

Key Features
Ticket Management: Track and manage customer tickets from submission to resolution
SLA Tracking: Monitor and ensure adherence to service level agreements
Analytics Dashboard: View key support metrics and performance indicators
Customer Portal: Allow customers to submit and track their support tickets
Team Collaboration: Enable support agents to work together on tickets
Technical Specifications
Frontend Framework: React 19 + TypeScript
UI Component Library: Shadcn UI
State Management: TanStack Query
Backend Framework: Next.js 14 (App Router)
Authentication: NextAuth.js + Google OAuth
Database: PostgreSQL
Cloud Infrastructure: Vercel + Neon
External Services:
Stripe: Payment processing and subscription management
Resend: Email delivery for notifications and password resets
Google AI: Text embedding for AI-powered features
